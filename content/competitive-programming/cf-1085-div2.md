**Problem:** [2207B](https://codeforces.com/contest/2207/problem/B)

## Summary

Bob has an array of size $m$. Over $l$ time steps, Bob increases one element by 1 each step. At $n$ fixed time steps, Alice may zero out one element of her choice. Both players play optimally — Bob tries to maximize the final maximum, Alice tries to minimize it. Find the minimum achievable maximum.

## Solution

The solution rests on two insights.

**Insight 1.** Every time Alice can zero out an element, she should always zero out the current maximum.

**Insight 2.** With $k$ zero-out steps remaining, Bob only needs to consider adding to the top $k+1$ elements.

### Proof of Insight 1

Suppose the current array, sorted in non-decreasing order, is $d_1 \leq \cdots \leq d_m$.

Let $\mathbf{d}^{-i}$ denote the sorted array after zeroing out element $i$:

$$\mathbf{d}^{-i} = (0,\ d_1,\ \ldots,\ d_{i-1},\ d_{i+1},\ \ldots,\ d_m) \quad (i \neq m)$$
$$\mathbf{d}^{-m} = (0,\ d_1,\ \ldots,\ d_{m-1})$$

Comparing componentwise, $\mathbf{d}^{-m} \leq \mathbf{d}^{-i}$ for all $i \neq m$. So zeroing out the maximum always yields the componentwise smallest resulting array.

It remains to show that a componentwise smaller array leads to a better (smaller) final answer for Alice. We prove this by induction on the number of steps $t$.

> [!abstract] Lemma
> Let $R(\mathbf{a}, t)$ be the final answer obtained from configuration $\mathbf{a}$ with $t$ steps remaining, given that both players play optimally. If $\mathbf{a} \leq \mathbf{b}$, then $R(\mathbf{a}, t) \leq R(\mathbf{b}, t)$.

We prove the lemma using induction.

**Base cases.** The statement is obviously true for $t = 0$. For $t = 1$, if Alice is the next player, the optimal move is to zero out the current maximum element, leaving the second largest element as the final answer. Because $\mathbf{a} \leq \mathbf{b}$, $R(\mathbf{a}, 1) = \text{second-max}(\mathbf{a}) \leq \text{second-max}(\mathbf{b}) = R(\mathbf{b}, 1)$. If Bob is the next player, the optimal move is to add 1 to the current maximum. Because $\mathbf{a} \leq \mathbf{b}$, $R(\mathbf{a}, 1) = \max(\mathbf{a}) + 1 \leq \max(\mathbf{b}) + 1 = R(\mathbf{b}, 1)$. Hence the statement holds for $t = 1$.

**Inductive step**: Assume the lemma holds for $t$; we prove it for $t + 1$. Consider two cases.

*Alice is the next player.* The optimal move is to zero out the current maximum. Let $\mathbf{a}^{-i}$ denote the configuration after zeroing out the $i$-th element of $\mathbf{a}$. Since $\mathbf{a}^{-m} \leq \mathbf{a}^{-i}$, by the inductive hypothesis $R(\mathbf{a}^{-m}, t) \leq R(\mathbf{a}^{-i}, t)$, so zeroing out $a_m$ — the maximum element — is Alice's best move. Since $\mathbf{a} \leq \mathbf{b}$, we have $\mathbf{a}^{-m} \leq \mathbf{b}^{-m}$, so $R(\mathbf{a}, t+1) = R(\mathbf{a}^{-m}, t) \leq R(\mathbf{b}^{-m}, t) = R(\mathbf{b}, t+1)$.

*Bob is the next player.* Suppose Bob's optimal move on $\mathbf{a}$ is to increment the $i$-th element, yielding $\mathbf{a}^{+i}$. Let $\mathbf{b}^{+j}$ be the configuration resulting from Bob's optimal move on $\mathbf{b}$. Since $\mathbf{a} \leq \mathbf{b}$, we have $\mathbf{a}^{+i} \leq \mathbf{b}^{+i}$, so by the inductive hypothesis $R(\mathbf{a}^{+i}, t) \leq R(\mathbf{b}^{+i}, t)$. By definition of Bob's optimal move on $\mathbf{b}$, $R(\mathbf{b}^{+i}, t) \leq R(\mathbf{b}^{+j}, t)$, because Bob wants to maximize $R$. Combining these two inequalities, $R(\mathbf{a}, t+1) = R(\mathbf{a}^{+i}, t) \leq R(\mathbf{b}^{+j}, t) = R(\mathbf{b}, t+1)$. $\square$

Note that proving the lemma also proves Insight 1 because the proof shows that whenever it is Alice's turn, her optimal move is to zero out the maximum element.
